# 🚀 Интранет-портал ООО "РАТЕКОМ" - OpenServer

## ⚡ Быстрый запуск (2 минуты)

### Шаг 1: Копирование проекта
```bash
Копируйте ВСЮ папку в:
C:\OpenServer\domains\ratekom
```

### Шаг 2: Импорт БД
1. OpenServer → Меню → phpMyAdmin
2. Login: root, пароль: пусто
3. Вкладка "Импорт"
4. Выбрать файл: `database/schema.sql`
5. Нажать "Выполнить"

### Шаг 3: Открыть в браузере
```
http://ratekom.openserver/
```

✅ **Готово!**

## ⚙️ Если не работает

### Сайт не открывается
1. Убедитесь, что OpenServer запущен (зелёная иконка)
2. Проверьте URL: `http://ratekom.openserver/`
3. Очистите кэш браузера (Ctrl+Shift+Del)

### Ошибка БД
1. Проверьте, что MySQL запущен
2. В phpMyAdmin проверьте, что БД `ratecom_intranet` создана
3. Пересоздайте БД (удалите и импортируйте заново)
4. Перезагрузите OpenServer (Меню → Остановить → Запустить)

### Белый экран
1. Откройте `logs/error.log` и посмотрите ошибку
2. Убедитесь, что папки `logs` и `uploads` существуют
3. Перезагрузите OpenServer

## 📝 Изменение учётных данных

### Изменить пароль администратора
1. Войдите как admin
2. Откройте phpMyAdmin
3. Таблица `employees` → найдите admin
4. Измените пароль (используйте `password_hash('новый_пароль', PASSWORD_BCRYPT)`)

### Изменить данные БД
Отредактируйте `config/database.php`:
```php
define('DB_HOST', 'localhost');
define('DB_USER', 'root');
define('DB_PASS', '');
define('DB_NAME', 'ratecom_intranet');
```
