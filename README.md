# Интранет-портал ООО "РАТЕКОМ"

Внутренний портал предприятия для управления информацией, сотрудниками и документами.

## Возможности

- 🔐 Система авторизации сотрудников
- 👥 База данных сотрудников
- 📰 Раздел новостей и объявлений
- 👤 Личные кабинеты сотрудников
- 📄 Документооборот и архив
- ⚙️ Панель администратора

## Требования

- PHP 7.4+
- MySQL 5.7+
- Apache/Nginx с поддержкой .htaccess

## Структура проекта

```
ratekom-intranet/
├── config/
├── public/
├── src/
├── templates/
├── database/
└── assets/
```

## Установка

1. Клонируйте репозиторий
2. Создайте базу данных
3. Импортируйте схему из `database/schema.sql`
4. Настройте `config/database.php`
5. Откройте сайт в браузере
