# 🚀 Быстрый старт для OpenServer 5.4.3

## Всего за 5 минут!

### Шаг 1: Копирование проекта (1 мин)

```bash
Копируйте папку проекта в:
C:\OpenServer\domains\ratekom
```

**Результат:** `C:\OpenServer\domains\ratekom\public\index.php`

### Шаг 2: Импорт базы данных (2 мин)

1. Откройте OpenServer (нажмите на иконку в трее)
2. Нажмите **Меню** → **phpMyAdmin**
3. Авторизуйтесь (login: root, password: пусто)
4. В верхнем меню выберите **Импорт**
5. Выберите файл `database/schema.sql`
6. Нажмите **Выполнить**

✅ **База данных готова!**

### Шаг 3: Создание папок (1 мин)

Откройте Command Prompt (от администратора) и выполните:

```bash
cd C:\OpenServer\domains\ratekom
mkdir logs
mkdir uploads
```

### Шаг 4: Открытие в браузере (1 мин)

```
http://ratekom.openserver/
```

✅ **Готово!**

## ❓ Возможные проблемы

### Не открывается сайт

1. **Проверьте, что OpenServer запущен**
   - Должна гореть зелёная иконка в трее

2. **Проверьте структуру папок**
   ```
   C:\OpenServer\domains\ratekom
   ├── public/
   ├── src/
   ├── config/
   ├── templates/
   ├── database/
   └── assets/
   ```

3. **Перезагрузите Apache и MySQL**
   - OpenServer → Остановить
   - OpenServer → Запустить

### Ошибка при подключении к БД

1. Убедитесь, что MySQL запущен (зелёный статус в OpenServer)
2. Проверьте, что БД `ratecom_intranet` создана (phpMyAdmin)
3. Очистите браузер (Ctrl+Shift+Del) и обновите страницу

### Белый экран / 500 ошибка

1. Откройте `logs/error.log` и посмотрите ошибку
2. Проверьте, что папки `logs` и `uploads` имеют права 755
3. Перезагрузите OpenServer

## 💡 Советы

- **Для разработки:** оставляйте OpenServer запущённым

- **Очистка кэша:** удалите папку `logs` → пересоздайте её
