# Инструкция по установке интранета ООО "РАТЕКОМ"

## Требования

- PHP 7.4 или выше
- MySQL 5.7 или выше
- Web-сервер (Apache с .htaccess или Nginx)
- Современный браузер

## Пошаговая установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/MOLOD777/ovchinnikov.git
cd ovchinnikov
```

### 2. Создание базы данных

```bash
mysql -u root -p < database/schema.sql
```

Или через phpMyAdmin:
1. Создайте новую БД `ratecom_intranet`
2. Импортируйте файл `database/schema.sql`

### 3. Настройка конфигурации

Отредактируйте файл `config/database.php`:

```php
define('DB_HOST', 'localhost');
define('DB_USER', 'ваш_пользователь');
define('DB_PASS', 'ваш_пароль');
define('DB_NAME', 'ratecom_intranet');
```

### 4. Создание необходимых директорий

```bash
mkdir -p logs
mkdir -p uploads
chmod 755 logs uploads
```

### 5. Запуск сервера

**Вариант 1: PHP встроенный сервер (для разработки)**

```bash
cd public
php -S localhost:8000
```

Откройте в браузере: `http://localhost:8000`

**Вариант 2: Apache**

1. Скопируйте папку в директорию DocumentRoot
2. Убедитесь, что включен модуль `mod_rewrite`
3. Настройте VirtualHost для `public` директории

### 6. Первый вход

Задача учитываемых данных:

- **Email:** admin@ratecom.ru
- **Пароль:** password123
- **Роль:** Администратор

Тестовый пользователь:

- **Email:** user@ratecom.ru  
- **Пароль:** password123
- **Роль:** Пользователь

## Структура проекта

```
ratekom-intranet/
├── config/              # Конфигурационные файлы
│   ├── config.php       # Основная конфигурация
│   └── database.php     # Настройки БД
├── public/              # Публичные файлы
│   ├── index.php        # Точка входа
│   └── assets/          # CSS, JS, изображения
├── src/                 # Исходный код
│   ├── pages/           # Страницы приложения
│   └── classes/         # Классы (будущее расширение)
├── templates/           # HTML шаблоны
├── database/            # Схема БД и миграции
├── logs/                # Логи приложения
└── uploads/             # Загруженные файлы
```

## Поддержка

При возникновении проблем:

1. Проверьте логи в `logs/error.log`
2. Убедитесь в правильности подключения БД
3. Проверьте права доступа к файлам
4. Обратитесь к администратору
